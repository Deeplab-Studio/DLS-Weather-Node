DLS Weather Node

Firmware kurulumu ve cihaz ayarları

1

Firmware yükle

v-

Kartınızı seçin, USB ile bağlayın ve yükleyin.

Tarayıcı Web Serial desteklemiyor. Chrome veya Edge kullanın. Kurulum için https veya localhost gerekir.
İlk yükleme flash'ı siler (10-60 sn). Güncelleme modunda ayarlarınız korunur.
2

Cihazı yapılandır

Ayarları USB üzerinden yazabilirsiniz. Cihaz Wi-Fi'ye bağlandıktan sonra kendi web arayüzünü de kullanabilirsiniz.

Not: Cihaz kendi web arayüzünü PIN ile korur. PIN, cihazın OLED ekranında ve seri portta görünür (pin komutu).
